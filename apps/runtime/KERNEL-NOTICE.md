# Linux kernel

`vmlinux` is the Linux kernel the device VMs boot: `vmlinux-6.18.35-197-debug`
from Kata Containers 3.32.0 (`kata-static-3.32.0-arm64.tar.zst`), the same one
Apple's `container` CLI installs by default. Linux is licensed under the
GNU General Public License, version 2.

- Binary: https://github.com/kata-containers/kata-containers/releases/tag/3.32.0
- Source and kernel configuration: https://github.com/kata-containers/kata-containers/tree/3.32.0/tools/packaging/kernel
- Linux: https://kernel.org
